Jarvis é um assistente pessoal que roda no computador do próprio usuário. Ele se conecta ao Google Agenda (Google Calendar) para ler e criar eventos a pedido do usuário.

Política de Privacidade

Última atualização: 27 de outubro de 2026

Quais dados acessamos. Com a sua autorização, o Jarvis acessa os eventos da sua conta do Google Agenda, usando a Google Calendar API.

Como usamos. Os dados são usados somente para mostrar, criar ou alterar eventos quando você pede ao assistente.

Onde ficam. Os dados e os tokens de acesso ficam armazenados apenas no seu próprio computador. O Jarvis não mantém servidor próprio e não guarda seus dados em outro lugar.

Compartilhamento. Não vendemos, não alugamos e não compartilhamos seus dados com terceiros. Não usamos os dados para publicidade.

Uso de dados do Google. O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Revogar acesso. Você pode remover o acesso a qualquer momento em myaccount.google.com/permissions e apagando os arquivos do Jarvis do seu computador.
